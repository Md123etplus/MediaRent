# MediaRent (Laravel)


Plateforme de location de matériel audiovisuel professionnel avec Laravel et Tailwind CSS.

## 🚀 Features
- Recherche avancée avec filtres techniques
- Gestion des réservations
- Système d'évaluation mutuelle
- Dashboard admin

## 🛠 Stack
- Laravel 10
- Tailwind CSS
- MySQL
